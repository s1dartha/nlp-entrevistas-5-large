# nlp-entrevistas-5-large
Este proyecto automatiza la codificación temática de entrevistas cualitativas mediante Modelos de Lenguaje de Gran Escala (LLMs). Originalmente diseñado para analizar la orientación política de estudiantes universitarios colombianos, el sistema utiliza embeddings generados por el modelo intfloat/e5-large y reducir el trabajo manual del investigador
